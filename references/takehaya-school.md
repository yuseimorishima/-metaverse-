# 竹早中学校モデルの参照資料

確認日：2026-10-27。公式サイトの校舎案内と施設写真を閲覧して制作しています。写真や案内図そのものはゲームに転載せず、材質・形状はコードで生成しています。

一次資料：東京学芸大学附属竹早中学校「[校舎案内](https://www2.u-gakugei.ac.jp/~takechu/building-info)」。

## 確認できた情報

- 施設マップにはL字状の中学校校舎、校舎アプローチ、下校庭、武道館が示されています。
- 1F：相談室、国語室、SUGOI部屋、音楽室、技術室、用務員室。玄関前にはピロティーの表示があります。
- 2F：事務室、リソースルーム、保健体育室、被服室、保健室、調理室、1学年教室、職員室。
- 3F：物理化学室、科学実験室、生物地学室、Dルーム、2学年教室。連絡通路の先にメディアセンター。
- 4F：英語室、美術室、グループ学習室、社会科室、視聴覚室、3学年教室。
- 5F：実習生室、屋上、会議室。
- 下校庭の掲載写真は緑色の人工芝。体育館は木床、高い窓、舞台、濃緑の幕、バスケットボールの設備があります。

## 今回の実装と近似の範囲

1Fの6室と体育館、ピロティー、中庭、下校庭を探索できます。上階は窓・床帯・屋上の外観だけを制作し、上階への移動は実装していません。以前の1階にあった理科室・図書室・美術室・1年教室という仮配置を置き換えました。食堂は設けていません。

廊下は幅3.4mの連続したL字に整理しています。部屋、体育館、ピロティー、校庭へのすべての開口は同じデータから描画と衝突判定を生成しています。下駄箱は通路の中央から壁際へ移動しました。スポーン地点の案内板も同じ配置を描きます。

公開案内は実測平面図ではありません。部屋の左右順、寸法、扉・窓・体育館の位置、床高、屋上形状、机の数、通路の形や幅、ゲーム内の方位は設計上の近似です。敷地全体や5階までの内部を正確に再現したモデルではありません。武道館・プール・小学校棟の内部は今回の探索範囲に含めていません。

## 検証

- `npm test`：全扉と両側の通行、通路中央と曲がり角の連続性、全室・体育館・ピロティー・下校庭への到達、壁・家具への衝突、5人のゲームルール。
- `npm run test:school`：実際の3Dメッシュに対する扉のレイ検証、キーボードで廊下全体から西の角を曲がって体育館へ入る移動、校庭への出口、PC・スマホの案内板と表示。
